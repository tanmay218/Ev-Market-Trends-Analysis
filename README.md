# Electric Vehicle Analytics Dashboard

## Project Overview

This project is an interactive **Power BI dashboard** created to analyze electric vehicle data. The dashboard gives a clear view of EV adoption trends, vehicle distribution, electric range, manufacturer performance, vehicle type comparison, and Clean Alternative Fuel Vehicle eligibility.

The main goal of this project is to convert raw electric vehicle data into useful business insights through data cleaning, modeling, DAX measures, and interactive Power BI visuals.
